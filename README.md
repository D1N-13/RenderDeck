# RenderDeck
An add-on designed for quick scene preparation for rendering and convenient setup management. It saves time and flexibly adapts to any project.

First and foremost: with just one click in RenderDeck, you can collect all the cameras in your scene and create ready-to-use setups, automatically categorized based on the camera names. The setups are immediately ready for rendering, meaning it takes only about 5 seconds to send all your cameras—or just selected ones—for rendering, without any additional setup or Batch Render configuration. And it also works for those who render using camera animations!

> [!TIP]
> **_The free version includes a 10-minute session with all features unlocked to let you test the full workflow (session resets when 3ds Max restarts)._**
> [RenderDeck_1_0_3_FREE.zip](https://github.com/user-attachments/files/32399626/RenderDeck_1_0_3_FREE.zip)


**Main features:**

- **Automatic setup creation:**

Create setups from all cameras in the scene—in any quantity—in just a few seconds.

- **Viewport display:**

Click on any setup to immediately switch the viewport to the corresponding camera view. This feature can be disabled.

- **Quick camera selection:**

Clicking a camera in the camera column immediately highlights the corresponding camera in the scene.

- **Convenient sorting:**

Easily rearrange setups in the list.

- **Camera grouping:**

Conveniently organize cameras into groups—for example, by room—and focus on one group without being distracted by others. You can also create custom groups and assign colors to them.

- **Camera direction:**

An arrow is displayed in front of each camera, showing its viewing direction in the top view.

- **Prefix setup:**

Add a common prefix to all saved setups—for example, the project name at the beginning of each setup name.

- **Working with options:**

When the Options feature is enabled, duplicating one or multiple setups preserves their base number and automatically assigns a new option number. For example: ... - 01 - OPT 1, then ... - 01 - OPT 2.

- **Status bar:**

Information about the current rendering process and ready setups is displayed at the bottom of the interface.

- **Send to Telegram:**

Automatically sends finished renders as files without quality loss immediately after rendering is complete.

- **Smart manual addition:**

When creating setups manually, cameras are automatically selected in order—without the need to expand the list every time.

- **Quick settings:**

Convenient selection of render format and image resolution.

- **Export:**

Integration with Batch Render, Pulze, and RenderFlow.
